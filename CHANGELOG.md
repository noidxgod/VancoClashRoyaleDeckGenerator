# Changelog

Все заметные изменения проекта фиксируются здесь.

Формат:
- `main` — рабочий сайт на GitHub Pages.
- `staging` — тестовая ветка для проверки новых функций.
- `vX.Y` — тег версии, к которому можно быстро откатиться.

## v4.26 — staging

- YouTube-чат переведён на бесплатный режим прямо через YouTube Data API в браузере.
- Backend больше не нужен для подключения чата на GitHub Pages.
- Добавлен вывод обычных сообщений чата, чтобы можно было проверить любой живой стрим.

## v4.25 — staging

- Добавлена история изменений прямо на сайт через кнопку `Что нового`.
- Добавлена тестовая ветка `staging`, чтобы проверять новые функции без обновления рабочего сайта.
- Созданы Git-теги версий `v3.6`—`v4.24` для быстрых откатов.
- Добавлена инструкция по релизам и безопасным откатам.

## v4.24 — staging

- Добавлен backend для чтения YouTube live-чата без хранения YouTube API ключа в `index.html`.
- Добавлена панель `YouTube чат` в инструменты сайта.
- Добавлены команды чата: `!колода`, `!хаос`, `!замена`, `!карта`, `!бан`, `!голос`, `!наказание`.
- Добавлена документация по локальному запуску и деплою backend на Vercel.

## v4.23 — production

- Упрощён финальный текст загрузки картинок: после предзагрузки показывается `Все карты загружены`.

## v4.22

- Добавлены локальные уменьшенные WebP-изображения карт.
- Карты в колоде используют локальные оптимизированные изображения для более быстрой загрузки.

## v4.21

- Предзагрузка картинок запускается автоматически без отдельной кнопки.

## v4.20

- Добавлена панель прогресса загрузки картинок.

## v4.19

- Исправлена ошибка генерации колоды на мобильных устройствах.

## v4.18

- Добавлены майские и июньские формы эволюций/героизмов.
