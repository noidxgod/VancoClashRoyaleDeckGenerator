# Changelog

Все заметные изменения проекта фиксируются здесь.

Формат:
- `main` — рабочий сайт на GitHub Pages.
- `staging` — тестовая ветка для проверки новых функций.
- `vX.Y` — тег версии, к которому можно быстро откатиться.

## v4.30 — staging

- Освежён тёмный дизайн: более глубокий фон с подсветкой, мягкие тени и градиенты на панелях, кнопках и карточках.
- У кнопок добавлены состояния наведения/нажатия/фокуса, у полей ввода — подсветка фокуса; обновлён скроллбар и чекбоксы.
- Улучшена адаптивность под телефон: добавлены брейкпоинты 640px и 400px, колода-сетка и блоки больше не вылезают за экран.
- Только визуальные правки (CSS). Логика, id, onclick, JS-функции, чат, пароль, генерация колод, фильтры, топ-колоды и данные карт не менялись.

## v4.29 — staging

- После правильного пароля окно ввода ключа скрывается.
- Длинные подсказки YouTube-чата спрятаны под значок `?`.
- Добавлена кнопка `Закрыть доступ` внутри открытых стрим-инструментов.

## v4.28 — staging

- Добавлен пароль на стрим-инструменты YouTube-чата.
- Поле ссылки на стрим и кнопка подключения скрыты до ввода пароля.
- Запросы к YouTube API блокируются кодом, пока стрим-инструменты закрыты.

## v4.27 — staging

- Добавлен приёмник стрим-команд: счётчики, пауза, очередь и ручное выполнение.
- Команды разделены на обычные зрительские и модераторские.
- Добавлены команды `!башня`, `!пул`, `!очистить`, `!статы`.

## v4.26 — staging

- YouTube-чат переведён на бесплатный режим прямо через YouTube Data API в браузере.
- Backend больше не нужен для подключения чата на GitHub Pages.
- Добавлен вывод обычных сообщений чата, чтобы можно было проверить любой живой стрим.

## v4.25 — staging

- Добавлена история изменений прямо на сайт через кнопку `Что нового`.
- Добавлена тестовая ветка `staging`, чтобы проверять новые функции без обновления рабочего сайта.
- Созданы Git-теги версий `v3.6`—`v4.24` для быстрых откатов.
- Добавлена инструкция по релизам и безопасным откатам.

## v4.24 — staging

- Добавлен backend для чтения YouTube live-чата без хранения YouTube API ключа в `index.html`.
- Добавлена панель `YouTube чат` в инструменты сайта.
- Добавлены команды чата: `!колода`, `!хаос`, `!замена`, `!карта`, `!бан`, `!голос`, `!наказание`.
- Добавлена документация по локальному запуску и деплою backend на Vercel.

## v4.23 — production
