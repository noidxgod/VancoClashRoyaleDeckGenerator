# Changelog

Все заметные изменения проекта фиксируются здесь.

Формат:
- `main` — рабочий сайт на GitHub Pages.
- `staging` — тестовая ветка для проверки новых функций.
- `vX.Y` — тег версии, к которому можно быстро откатиться.

## v5 — production

Новый функционал:
- YouTube-чат теперь работает прямо на GitHub Pages через YouTube Data API: можно вставить ссылку на live-стрим, видеть обычные сообщения и найденные команды.
- Добавлен приёмник стрим-команд со счётчиками, паузой, очередью и ручным выполнением.
- Добавлены команды зрителей: `!колода`, `!хаос`, `!замена`, `!карта <название>`, `!башня`, `!статы`, `!голос <вариант>`, `!наказание`.
- Добавлены модераторские команды: `!бан <карта>`, `!пул <все|ретро|хаос>`, `!очистить`.
- Стрим-инструменты закрыты паролем: без доступа скрыты ссылка на стрим, подключение к API и выполнение запросов.

Кратко:
- Добавлены история изменений на сайте, документация по релизам и безопасному откату.
- Обновлён тёмный дизайн, расположение панелей, кнопки, поля и адаптация под телефон.
- Панель загрузки карт после успешной загрузки подсвечивается и автоматически исчезает.
- Оставлены backend-скрипт и документация для альтернативного режима YouTube-чата.
